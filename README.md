# Motion Code

Site do workshop ao vivo **Motion Code** (Ueda Agency), 12/11/2026.

- `index.html`: página completa (HTML, CSS e JS sem build)
- `assets/`: logo, favicon e os 4 vídeos motion feitos em código, com trilha
- `vercel.json`: cache longo para os arquivos de `assets/`

Para trocar os links de compra, edite o objeto `CHECKOUT` no fim do `index.html`.
